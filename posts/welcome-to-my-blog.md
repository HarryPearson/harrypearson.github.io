Hey, I'm Harry — welcome to my new blog.

This is where I'll be writing about **ServiceNow**, general engineering, and the odd post about fitness or finance.

## Why a blog?

Mostly as a place to write things down properly instead of losing notes in random text files. It also means adding a new post is as simple as:

1. Drop a new `.md` file in the `posts/` folder
2. Add an entry to `posts/posts.json`
3. Commit and push

No build step, no CMS.

## Markdown support

This page renders standard markdown, so you get things like:

- Bullet points
- **Bold** and *italic* text
- [Links](https://harrypearson.co.uk)
- Inline `code` and full code blocks:

```js
function hello() {
  console.log("Hello, world!");
}
```

> Blockquotes work too.
